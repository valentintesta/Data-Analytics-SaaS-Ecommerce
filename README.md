### 2. E-Commerce Analytics Project: SQL, Python, and Power BI

Deep-dive analytics workflow for an e-commerce company combining database analysis and Power BI visualization. This project builds a normalized database and BI suite using SQL, Python for data preparation and requests, and Power BI for executive reporting.

**Folder:** `Ecommerce-Analytics-SQL-PowerBI/`

**Business Goal:**
Analyze e-commerce data to discover trends, reduce product returns, and improve customer satisfaction. The project can help ensure that operations are scalable and financially sustainable.

**Key Tools Used:**
- SQL: Database schema and ETL analysis
- Python: Data preparation and import
- Power BI: Executive reporting and portfolio tracking

**Main Dashboard Metrics:**
- Total Revenue: $3.2M
- Return Rate: 18.5%
- Top Customer Count: 150+ high-value customers
- Top Product Categories: Electronics (top overall)
- Customer Test Selection: Distribute across multi-touch and buyer profiles

**Key Insights:**
- Top products: Specific SKU analysis, demographics, brand curves
- Returns analysis: Late collection, damaged items
- Product insights: Price vs quality, category distribution, sales trends
- Customer Segmentation: Segment by RFM, identify best customer value, high-value purchase patterns
